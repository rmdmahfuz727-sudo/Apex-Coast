🏎️ Apex Coast

A neon-inspired mobile racing game.

Welcome to Apex Coast! This project is developing a stylish racing experience with a neon-inspired visual identity and a simple in-game menu.

«🚧 Status: Beta / In Development»

🎮 Features

- 🏁 Drive — enter the driving experience
- 🚗 Garage — access the garage menu
- ⚙️ Settings — access game settings
- 🌃 Neon-inspired visual design
- 📱 Android APK builds for testing

Features and gameplay may change as development continues.

📥 Download

Get the latest beta: "Apex Coast Releases" (https://github.com/rmdmahfuz727-sudo/Apex-Coast/releases)

1. Open the Releases page.
2. Download the APK asset from the latest release.
3. Install it on a compatible Android device, following Android's security prompts if applicable.

Only install APK files you trust.

🧪 Beta Testing

This is an early build. You may encounter bugs, incomplete features, or performance issues.

When reporting a bug, include:

- Your device and Android version
- Steps to reproduce the issue
- What you expected and what happened
- A screenshot or crash log, if available
